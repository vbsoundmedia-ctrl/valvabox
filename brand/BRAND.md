# Valvabox brand

## Logo
The mark is a rounded **box** holding four equalizer bars. Their tops trace a **V**, and a gold **play button** sits at the point of the V. It stands for sound, video and the Valvabox name in one icon.

| File | Use |
|---|---|
| `logo-mark.svg` / `.png` | App icon, favicon, social avatar |
| `logo-horizontal.svg` / `.png` | Light backgrounds |
| `logo-horizontal-dark.svg` / `.png` | Dark backgrounds |

The wordmark is set in lowercase **valva** + **box**, with "box" in green.
Before printing, convert the SVG text to outlines (Inkscape: *Path → Object to Path*) so it doesn't depend on the font being installed.

## Colours
| Name | Hex | Use |
|---|---|---|
| Midnight Ink | `#110D24` | Backgrounds, text, logo box |
| Valva Green | `#19D27F` | Primary buttons, money and success |
| Deep Green | `#0FA968` | Green text on white |
| Violet | `#8B5CF6` | Accents, gradients, links |
| Naira Gold | `#FFC233` | Play button, highlights, badges |
| Paper | `#FAF9FF` | Page background |
| Muted | `#6B6785` | Secondary text |

Gradient: Valva Green → Violet, bottom to top (logo bars) or left to right (headlines).

## Type
- Headlines: **Space Grotesk** 600/700 (Google Fonts)
- Body and UI: **Inter** 400/500/600 (Google Fonts)
- The ₦ sign renders correctly in Inter. Keep Inter in the font stack after Space Grotesk.
